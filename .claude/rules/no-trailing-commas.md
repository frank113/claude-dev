# No Trailing Commas

When writing code do not end any block with a trailing comma. We do not want trailing commas in any other coding context in which they appear. Examples of places where this should never be done include but are not limited to:

+ Parameters
+ Arrays
+ Dictionary / Object literals
+ Multi-line function calls
+ Imports

## Examples

Good code:

```python
out = franks_function(
    input1 = "frank",
    input2 = "alex"
)
```
